# 🕸 GiftGraph Bot

Telegram-бот для визуализации социальных связей через подарки профилей. Строит граф в стиле Obsidian: тёмный фон, фиолетовые узлы, анимированные рёбра.

## Что умеет

- `/start` — главное меню с кнопкой «Построить граф»
- `/search` — начать настройку нового графа
- `/search @username` — открыть настройки графа с указанным пользователем
- `/search @u1 @u2` — настроить поиск пути между пользователями
- `/subscribe` — баланс, покупка попыток и подписка через Telegram Stars
- `/promo КОД` — активировать промокод
- `/help` — полная справка

## Быстрый старт

### 1) Установка зависимостей

```bash
pip install -r requirements.txt
```

Для PNG-рендеринга нужен Chrome или Chromium:

```bash
# Ubuntu/Debian
apt-get install -y google-chrome-stable
# или
apt-get install -y chromium-browser
```

### 2) Настройка `.env`

```env
BOT_TOKEN=7123456789:AAF...
API_ID=12345678
API_HASH=abcdef1234567890abcdef
TELETHON_SESSION=userbot
PROMO_CODES={"LAUNCH2024": 30, "YEAR2024": 365}
```

`API_ID` и `API_HASH` берутся из https://my.telegram.org/apps.

### 3) Создание Telethon-сессии

```bash
python setup_session.py
```

Введите номер телефона и код из Telegram. После этого появится файл `userbot.session`.

### 4) Запуск

```bash
python main.py
```

## Построение графа

Откройте `/start` и нажмите «Построить граф». Бот проведёт по шагам в одном сообщении:

1. Тип: дерево связей одного пользователя или цепь между двумя.
2. Ники: `@username` для дерева, `@user1 @user2` через пробел для цепи. Символ `@` необязателен.
3. Глубина от 1 до 10; рекомендуется начать с 2.
4. Подарки: публичные или все, включая анонимные.
5. Учитывать или исключить ботов.
6. Проверка параметров и кнопка «Начать построение».

«Назад» возвращает к предыдущему шагу, «Отмена» — в главное меню. Настройка не расходует бесплатные поиски. После перезапуска бота откройте новое меню через `/start`.

Дерево раскрывает связи вокруг одного пользователя. Цепь показывает кратчайший найденный путь и до 8 соседей на звено. Граф ограничен 120 узлами.

## Данные и лимиты

- SQLite база: `giftgraph.db`
- Бесплатно: 3 попытки на аккаунт
- Попытки без срока действия: 1 за 3 ⭐, 5 за 12 ⭐, 10 за 20 ⭐
- Одна попытка — один запуск построения графа; настройка не расходует попытки
- Сначала расходуются бесплатные попытки, затем купленные; активная подписка сохраняет оба баланса
- Подписка: Telegram Stars
- Промокоды: задаются через `PROMO_CODES`
- Максимум: 120 узлов на один граф

## Визуализация

- фон: `#0d1117`
- стартовый узел: белый
- обычный узел: фиолетовый
- узел на пути: янтарный
- анонимный узел: серый
- рёбра: тёмно-серые

## Баланс купленных попыток

Цены пакетов задаются в `config.py` (`SEARCH_PACKS`). Баланс хранится в `users.paid_searches`, квитанции — в `search_payments`. Начисление и запись квитанции выполняются одной транзакцией; повторный `telegram_payment_charge_id` не увеличивает баланс. Попытка списывается атомарно при запуске поиска после проверки подключения сервиса.

При запуске `init_db()` добавляет поле баланса к существующей базе, сохраняя пользователей, подписки и промокоды. Миграция повторяемая. При откате кода оставьте новые поле и таблицу: старый код их игнорирует, а баланс сохранится для возврата к новой версии. Перед обновлением рабочей базы создаётся резервная копия; её нельзя восстанавливать поверх новых оплат без сверки квитанций.

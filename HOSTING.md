# Запуск и тестирование GiftGraph Bot

## Быстрое вкл/выкл (для тестов)

Из терминала, в папке проекта:

```bash
./manage.sh start     # запустить в фоне
./manage.sh stop      # остановить
./manage.sh restart   # перезапустить
./manage.sh status    # статус + PID
./manage.sh logs      # живые логи (Ctrl+C для выхода)
```

## Секреты

Хранятся в `.env` (в гите игнорируется):
`BOT_TOKEN`, `API_ID`, `API_HASH`, `TELETHON_STRING_SESSION`.

## Userbot-сессия (Telethon)

Боту нужна сессия реального аккаунта Telegram (не бота) — через неё идёт доступ к API подарков.

Сгенерировать строковую сессию:

```bash
python gen_session.py
```

Ввести номер телефона, код из Telegram (и пароль 2FA, если есть). Полученную строку вставить в `.env`:

```
TELETHON_STRING_SESSION=<строка>
```

Строковая сессия предпочтительнее файла `userbot.session`: её легко переносить и она не «залипает» при параллельных запусках.

## Рендер графа

Основной режим — самодостаточный HTML (никакой Chromium не нужен). PNG-режим (`render_graph_to_png`) сейчас не используется.
